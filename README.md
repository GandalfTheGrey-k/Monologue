# Monologue

[![Download Monologue_v.1.zip](https://img.shields.io/badge/Download-Monologue__v.1.zip-2ea44f?style=for-the-badge&logo=github)](https://github.com/GandalfTheGrey-k/Monologue/releases/latest/download/Monologue_v.1.zip)

A roleplay voice addon for **WoW Forever**. Your character talks on their own: lines when they pull with a big move, greetings for friends, call-outs for rivals and reactions to the world, all in their race's accent. You shape who they are on the **My Voice** tab.

> **Alpha build.** Things will break. Please report them with `/mono bug`.

## ⚠️ Use the download button above

Do **not** use GitHub's green **Code → Download ZIP** button. That ZIP's folder is named `Monologue-main`, and WoW won't load the addon from it. The **Download** button above always gets the latest release, already packaged as a `Monologue_v.1` folder.

## Install

1. **Extract** the ZIP so the `Monologue_v.1` folder sits in
   `World of Warcraft\_forever_\Interface\AddOns\`
   (`Monologue_v.1.toc` must be directly inside `Monologue_v.1`, not in a second folder inside it).
2. **Start the game**, or type `/reload` if you're already logged in. On the character screen, make sure Monologue is ticked under **AddOns**.
3. **Type `/mono`** to open the settings and the My Voice studio. If something goes wrong, type **`/mono bug`** and paste the report into Discord.

More help (commands, Strict Safe-Mode, troubleshooting) is in [README.txt](README.txt), which is also inside the download.
